# Video Tutorials

Videos are great for seeing how things connect. The links below are **YouTube searches**, not individual videos, so they never go stale. Pick a recent result (check the upload date, since tools change quickly), skim the comments for "outdated" warnings, and favor videos that build something similar to this project.

## Channels that cover this material well
These channels regularly publish Node, JavaScript, and web-development tutorials: **Traversy Media**, **Fireship** (fast concept overviews), **Web Dev Simplified**, **The Net Ninja**, **freeCodeCamp.org** (long full courses), **Programming with Mosh**, **Academind**, and **Hussein Nasser** (backend and networking concepts). Search the channel name plus the topic.

## Tips for learning from video
- Code along instead of just watching; pause and type it yourself.
- Match versions: this project uses Express 4, Node 20+, and Jest 29.
- If a video's code differs from this project (for example uses ES modules `import` instead of `require`), keep this project's style.
